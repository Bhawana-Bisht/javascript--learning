## 💻 How to Run the Code

### Run JavaScript with Node.js

1. Install [Node.js](https://nodejs.org/) if you haven't already.
2. Clone this repository:

   ```bash
   git clone https://github.com/Bhawana-Bisht/javascript--learning.git
   ```

3. Open the project folder in VS Code.
4. Run a JavaScript file from the terminal:

   ```bash
   node 01_basics/01_variable.js
   ```

### Run DOM Practice Files

Open an HTML file from the `05_dom` folder in your browser to explore the examples involving HTML and JavaScript.
